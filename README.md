# RATEIT

RATEIT — соревновательная платформа для **Standoff 2**, вдохновлённая форматом FACEIT.

Проект планируется в двух клиентах:
- Android-приложение.
- Telegram Mini App внутри Telegram-бота.

Оба клиента должны работать с общими аккаунтами, API и базой данных.

> **Статус:** этап фиксации требований и проектирования. Реализация и интеграции ещё не подтверждены.

## Основные разделы приложения

Нижняя навигация состоит из пяти кнопок:
1. **Главная**
2. **Друзья**
3. **Играть** — центральная кнопка запуска подбора матча.
4. **История матчей**
5. **Профиль**

## Аккаунт и авторизация

Планируемые способы входа:
- Google.
- Telegram.
- Facebook — если получится реализовать интеграцию.

Один пользователь RATEIT должен иметь единый профиль на Android и в Telegram Mini App. При привязке нескольких способов входа они должны вести к одному аккаунту, а не создавать дубликаты.

Профиль должен хранить ник, Standoff 2 ID, часы, ELO, уровень, статистику, друзей и историю матчей.

## Профиль игрока

В верхней части профиля показываются:
- Ник игрока.
- Standoff 2 ID.
- Количество часов в Standoff 2.
- Уровень, эмблема и ELO.

Ниже отображаются:
- K/D/P — показатели игрока (точный состав и формулы показателей нужно определить при реализации).
- Общее количество сыгранных матчей.
- Полоса результатов: зелёная часть — победы, красная — поражения.
- Процент побед, расположенный по центру.
- Топ карт: карта с наибольшим числом побед и карта с наибольшим числом поражений.

Статистика должна рассчитываться по матчам, зарегистрированным в RATEIT.

## Часы и префикс

При регистрации пользователь вводит свой Standoff 2 ID. Планируется проверять профиль и получать количество наигранных часов.

Префикс часов округляется **вниз до ближайших 10 часов**:

`prefix = floor(hours / 10) * 10`

Примеры:
- 178 часов → `170+`
- 187 часов → `180+`
- 193 часа → `190+`
- 205 часов → `200+`

Префикс — это отображение часов. Для подбора матчей используется фактическое количество часов, если его удастся надёжно получить.

### Ограничение по часам при подборе

Разница в часах между игроками должна быть **не больше 50 часов включительно**:

`abs(playerHours - currentPlayerHours) <= 50`

Примеры:
- 100 и 150 часов → подходят.
- 100 и 151 час → не подходят.
- 100 и 80 часов → подходят.
- 100 и 49 часов → не подходят.

Нужно дополнительно определить, проверяется ли это ограничение относительно каждого игрока в матче или относительно другого общего ориентира (например, среднего значения команды).

## Система ELO и уровней

После регистрации новый игрок получает **751 ELO — 3-й уровень**.

Текущая согласованная таблица:

| Уровень | Диапазон ELO |
|---|---:|
| Challenger | Топ-1000 игроков |
| 10 | 2000+ |
| 9 | 1750–1999 |
| 8 | 1530–1749 |
| 7 | 1350–1529 |
| 6 | 1200–1349 |
| 5 | 1050–1199 |
| 4 | 900–1049 |
| **3** | **751–899** |
| 2 | 501–750 |
| 1 | 100–500 |

Границы уровней обновлены по просьбе владельца проекта: следующий уровень начинается на указанном минимальном ELO (например, уровень 4 начинается с 900).

Эмблемы уровней должны соответствовать предоставленным пользователем визуальным референсам. Сами файлы изображений ещё нужно добавить в репозиторий. Challenger — отдельный статус для топ-1000 игроков.

## Матчи и соревновательные функции

Планируемые функции:
- Подбор игроков и формирование матча.
- Рейтинг ELO и уровни.
- Команды и распределение игроков по командам.
- История матчей и результаты.
- Статистика игроков и карт.
- Друзья.
- Лидерборды.
- Турниры.
- Уведомления.

Режимы 5×5 и 2×2 обсуждались как возможные варианты, но окончательный список режимов ещё не утверждён.

### Создание игровых комнат

Желаемый сценарий автоматизации: игровой агент создаёт комнату с нужными настройками, приглашает участников, распределяет их по командам и запускает матч.

**Техническое ограничение:** Telegram-бот сам по себе не управляет Standoff 2. Для полной автоматизации потребуется подтверждённый официальный API или разрешённый и надёжный способ взаимодействия с игрой. Наличие такой возможности пока не подтверждено.

Если официальная автоматизация недоступна, для первой версии можно использовать безопасный полуавтоматический сценарий: RATEIT подбирает игроков и формирует команды, а капитан или игрок создаёт комнату вручную; участники подтверждают готовность, после матча результат фиксируется в RATEIT.

## Важные технические вопросы

До реализации автоматической проверки профиля необходимо выяснить, существует ли доступный и разрешённый источник данных, который позволяет по Standoff 2 ID достоверно получать количество часов. Пока это не подтверждено, нельзя обещать мгновенную автоматическую проверку.

Также предстоит выбрать и настроить:
- Общий backend API для Android и Telegram Mini App.
- Базу данных и схему аккаунтов, матчей и статистики.
- Технологии Android-клиента и Telegram Mini App.
- Хостинг, авторизацию и безопасное хранение секретов.
